# Server-Side Development

Repository containing coursework and practical exercises for the Server-Side Development module.

## Projects

### [`myfirstproject`](./myfirstproject)
A Laravel application introducing core concepts:
- **Routing & Views:** Web routes configured in `routes/web.php` for home, jobs listing, dynamic job detail, and contact pages.
- **Blade Layouts & Components:** Reusable `<x-layout>` and custom `<x-nav-link>` navigation components with active state handling.
- **Data Handling:** Passing dataset arrays to views, rendering with `@foreach`, and querying specific records using `Arr::first()`.
- **Styling:** Styled using Tailwind CSS.
